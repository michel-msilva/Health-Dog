Projeto desenvolvido para o curso do SENAI PROGRAMADOR FRONT-END.
Por se tratar de um projeto acadêmico foi desenvolvido como uma single-page application via CDN.
Com o intuito de demonstrar conhecimento e habilidades nas tecnologias ensinadas em aula (HTML5, CSS3, BOOTSTRAP, JAVASCRIPT, NODEJS e REACT). 
O site Health Dog tem como intuito levar e centralizar informações e conhecimentos referente a cuidados, bem-estar e alimentação canina.
